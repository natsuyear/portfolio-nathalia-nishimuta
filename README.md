# Portfólio Nathália Nishimuta

Site pessoal de portfólio: "Designer de produto: da marca ao código".

## Como abrir
Abra `index.html` no navegador. Todos os arquivos ficam na mesma pasta (sem subpastas), então para publicar no GitHub Pages basta subir tudo na raiz do repositório e ativar Settings → Pages → Deploy from branch → main → root.

## Conteúdo
- `index.html`: a página (Sobre, Certificados, Formação, Workshops, Habilidades, Projetos com o carrossel do case Heloísa, Contato)
- `hark.css`, `hark-hero.css`, `hark.js`: estilos e scripts
- `foto.jpg`: foto de perfil
- `cert-*.jpg/png`: certificados
- `helo-slide-1..9.jpg` e `estudo-de-caso-heloisa.pdf`: estudo de caso Heloísa Nail Designer
